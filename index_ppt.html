FlexiGig

Part-Time Jobs Reimagined — A Premium Glassmorphism Bento Grid Portal

March 25, 2026
Project Presentation

Executive Summary

Vision

A next-gen platform connecting local seekers and employers with modern UX.

Strategy

Simplified hiring via role-specific dashboards and real-time feedback.

Innovation

First job portal to implement a comprehensive "Glassy Bento" system, blending utility with high-end aesthetics.

The Problem Statement

Dated Interfaces

Most gig platforms feel like legacy software from the early 2010s, with cluttered layouts.

Friction in Hiring

Complex forms and slow feedback loops discourage quick part-time matching for local businesses.

Information Overload

Job seekers are overwhelmed by walls of text. FlexiGig uses Bento Tiles to make data digestible and interactive.

Core Objectives

  • Aesthetic Excellence: Pixel-perfect UI with cutting-edge CSS glassmorphism effects.
  • Dual-Mode Functionality: Distinct, optimized Seeker vs. Employer experiences.
  • Real-Time Efficiency: Optimized "Quick Apply" and "Hiring Funnels" with instant feedback.

High-Efficiency Discoveries

Advanced filtering and instant application tracking for the Seeker experience.

Seeker Journey

1. Discover

Browse categorized gigs (Cafe, Tech, Retail) with real-time availability counters.

2. Quick Apply

Apply with a single click — no redundant form-filling for every individual job.

3. Track

Real-time status updates in a visual pipeline: 'Applied' → 'Interview' → 'Hired'.

Employer Command Center

Full applicant lifecycle management from a single glassmorphism tile.

Employer Workflow

Applicant Management

Integrated modal to manage candidate lifecycles (Reject, Waitlist, Interview, Selected).

Instant Feedback

Real-time toast notifications for new applications as they arrive.

Analytics Tile

Track active listings and total applicant counts at a glance with live updates.

Technology Stack

Frontend

Vanilla JS/HTML5, CSS Grid Lab, Backdrop Filters

Backend

Node.js, Express, JWT Auth, bcrypt Security

Database

High-Performance SQLite (Better-SQLite3)

Relational Core Architecture

Users & Roles

Secure JWT-based auth with distinct permissions for Seekers and Employers.

Job Ledger

Dynamic listing table with real-time relationship to posters and status tracking.

Application Junction

Synchronized junction table preventing duplicate entries and managing granular funnel states.

Design System Identity

Glassmorphism

Crystalline blurred backgrounds.

Bento Grid

Apple-inspired modular scaling.

Mesh Gradients

Fluid, animated color blobs.

Typography

Inter & Space Grotesk pairing.

The Road Ahead

  • AI Matching: Intelligent gig recommendations based on user skills and history.
  • In-App Chat: Real-time crystalline chat interface for seamless interviews.
  • Mobile App: Native iOS/Android apps following the Bento Design Language.
  • Gamification: Reward points for reliable seekers and top-rated employers.

Conclusion

FlexiGig proves that utility and aesthetics can coexist beautifully in HR technology.
